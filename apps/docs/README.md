# GenOffice Docs

Public documentation site for GenOffice V2 (`@gen-office/docs`).

- **Stack:** Fumadocs + Next.js + Fumadocs MDX
- **Plan:** [`.docs/plan/docs-site-plan.md`](./.docs/plan/docs-site-plan.md)

```bash
pnpm install
pnpm -C apps/docs dev
```

Dev server defaults to port **3001** (demo uses 5173 / 8081).
