# GenOffice Docs

GenOffice is a React framework for enterprise back-office UIs.

How a new app usually starts:

1. **GenFrame** — app shell (layout, menu, workarea, navigation)
2. **GenDataGrid / GenDataGridCrud** — screens inside the workarea
3. **Theme / UI** — tokens and Radix-based components
