# GenOffice Docs

GenOffice는 엔터프라이즈 백오피스 UI를 위한 React 프레임워크입니다.

새 앱의 일반적인 시작 순서:

1. **GenFrame** — 앱 셸 (레이아웃 · 메뉴 · workarea · 네비게이션)
2. **GenDataGrid / GenDataGridCrud** — workarea 안 화면
3. **Theme / UI** — 토큰 · Radix 컴포넌트
