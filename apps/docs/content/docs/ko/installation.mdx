# Installation

## 선행 조건

- Node.js 20+
- React 19
- pnpm 9+ (이 모노레포)

## 권장 스타터 세트 (새 백오피스 앱)

```bash
pnpm add @gen-office/theme @gen-office/ui @gen-office/gen-frame @gen-office/gen-datagrid
```

| 패키지 | 시점 |
| --- | --- |
| `@gen-office/mdi` | 멀티 탭(MDI) 네비게이션 |
| `@gen-office/gen-datagrid-crud` | ActionBar CRUD 페이지 |
| `@gen-office/gen-chart` | 차트 |

셸 구성은 [Quick Start](/docs/quick-start)를 따르세요.

## 워크스페이스 (이 저장소)

패키지는 pnpm workspace로 이미 연결됩니다.

```bash
pnpm install
pnpm -C packages/theme build
pnpm -C packages/gen-frame build
pnpm -C packages/gen-datagrid build
```

앱(`apps/demo`, `apps/docs` 등) 의존성 예:

```json
{
  "dependencies": {
    "@gen-office/theme": "workspace:*",
    "@gen-office/ui": "workspace:*",
    "@gen-office/gen-frame": "workspace:*",
    "@gen-office/gen-datagrid": "workspace:*",
    "@gen-office/gen-datagrid-crud": "workspace:*"
  }
}
```

## CSS 로드 순서

1. `@gen-office/theme/index.css` — 디자인 토큰
2. `@gen-office/ui/index.css` — UI (필요 시)
3. `@gen-office/gen-frame/index.css` — 프레임 크롬
4. `@gen-office/gen-datagrid/index.css` — 그리드
5. `@gen-office/gen-datagrid-crud/index.css` — CRUD (필요 시)

앱에서 쓰는 경우 `@gen-office/theme`의 `ThemeProvider`로 감쌉니다.

## Docs 로컬 실행

```bash
pnpm -C apps/docs dev
```

포트 **3001**. 영어 `/en/docs`, 한국어 `/ko/docs`.
